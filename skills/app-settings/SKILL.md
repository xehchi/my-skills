# מסך הניהול

> מודלי הישויות: `docs/spec.md` §3.12–3.14. קודם לבדוק שם, לא להמציא עמודות.

## 1. משתמשים (`users` sheet)

| עמודה | טיפוס | הערות |
|---|---|---|
| `email` | text | מפתח — המייל של חשבון גוגל, lowercase |
| `name` | text | שם תצוגה |
| `role` | enum | `admin` / `member` (כרגע כולם `admin`) |
| `active` | bool | `false` = נחסם בלי מחיקה |
| `created_at` | ms | |

- **אין הרשמה.** ההוספה — ידנית בגיליון או דרך מסך ההגדרות (אם יש). אין "הזמנה במייל".
- מייל שגוי = מי שלא ברשימה נדחה (`security-auth`).
- **`active: false`** — החסימה הסטנדרטית. **לא למחוק** שורה של מי שכתב מאמרים/פניות.
- **ה-admin האחרון** — לא ניתן להשבית או להפוך ל-member (`RULE`).

## 2. קונפיגורציה — איפה שומרים כל דבר

| מה | היכן |
|---|---|
| Progress/Permissions/`migrations`/`ver:*` | `ScriptProperties` |
| הגדרות שהמשתמש עורך (שם המערכת, לוגו, צבע) | גיליון `settings`: `key` \| `value` — קטן, שמור כמו שהוא |
| רשימת מורשים | `users` sheet |
| סודות (אם יהיו) | `ScriptProperties` — לא בגיליון |

```js
function getSetting(key, fallback) {
  var row = settingsRepo.get(key);
  if (!row) return fallback;
  try { return JSON.parse(row.value); } catch (e) { return row.value; }   // גמיש: טקסט או JSON
}
```
- **`JSON.parse` עם fallback** — אחרת ערך כמו "כחול" שובר את המסך.
- הטוקנים למראה — `--c-accent` וכדומה (`gas-client` §3). שינוי צבע מהמסך = עדכון CSS variable = **זהירות מה־ערך**: רק ערך צבע מאומת. מילון סגור או `#rrggbb`.

## 3. יומן פעולות (`activity_log`)

```js
function logActivity(user, entityType, entityId, action, diff) {
  activityRepo.append({
    user_email: user.email, entity_type: entityType, entity_id: entityId,
    action: action,                     // create | update | status | delete | move
    diff: diff ? JSON.stringify(diff) : null,
    created_at: Date.now()
  });
}
```
- **מתי:** יצירה, שינוי סטטוס, העברה בין חדרים, מחיקה, הוספת/הסרת משתמש, סגירת תקלה. **בכל נתיב כתיבה מה-dispatcher.**
- **`diff`** — `{ field: [before, after] }`. רק השדות שהשתנו. לא את כל האובייקט.
- **יומן בבית הספר:** 3 אנשים → לא ענק. לשמור שנה; ארכיון לגיליון `activity_log_2025` כשעובר ~10k שורות.
- **מה לא נכנס ליומן:** קריאות, שינויי "נקרא", טעינת מסך. רק שינויים.

## 4. תיעוד טיפול (השאלה הפתוחה)

`docs/session-notes.md` §4.5 — **פתוח**: "האם חובה לתעד טיפול כדי לסגור תקלה?".
- **ברירת מחדל נוכחית**: `resolution` חובה בסגירת תקלה (`domain-flow` §3).
- **אם המשתמש יבחר "לא חובה"** — ה-yומן עדיין מתעד סגירה, אבל `resolution` ריק.
- **התעד את ההחלטה** ב-`docs/spec.md` §11 כשהמשתמש יחליט.

## 5. גיבוי

- **מתוזמן** — `backupDaily_()` ב-`gas-runtime` §6. 30 גרסאות.
- **ידני** — כפתור "גיבוי עכשיו" במסך הניהול (admin), מוחזר "נוצר גיבוי: גיבוי - dd/mm/yyyy HHmm".
- **שחזור** — פתיחת הגיבוי ב-Drive והורדה. **לא** לשחזר על הגיליון החי בלי אישור מפורש.
- **ייצוא XLSX "לשמירה"** — לקובץ הזמני במחשב. גיבוי ≠ ייצוא: גיבוי = העתק הגיליון כולו.

## 6. מסך ההגדרות — מינימום
| מקטע | תוכן | שלב |
|---|---|---|
| פרופיל | שם תצוגה, מייל (קריאה בלבד) | 1 |
| משתמשים | רשימה, הוספה/השבתה | 1 |
| יומן | סינון לפי ישות/תאריך; 20 אחרונים בטבלה | 8 |
| גיבוי | "גיבוי עכשיו" + רשימת הגיבויים האחרונים | 8 |
| סקריפטים | קריאה/כתיבה/הורדה | 8 |

- **אין** "שחרור גישה"/"התחברות כמישהו אחר". **לא לממש** (`docs/spec.md` §12).

## 7. דגלים אדומים
- להסיר את עצמך מה-admin האחרון.
- לשנות `role` מהקליינט — הבדיקה בשרת מה-`ctx.user` (`gas-api` §2).
- לכתוב את כל אובייקט הישות ל-`diff` — יומן ענק, ופרטיות של מייל.
- לשחזר גיבוי על הגיליון החי בלי אישור.
- להחזיק סיסמה/טוקן בגיליון `settings`.
- לשנות עמודה ב-`users` באמצע — זה מה שכל הבדיקות מחפשות. מיגרציה בלבד.
